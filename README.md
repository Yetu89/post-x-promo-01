([bounty page](https://make.fun/bounty/post-x-promote-make-your-own-bounty-01)): one post of my own on X
that quotes [make.fun's post](https://x.com/makefunai/status/2124915864336236646), with a photo of its
own attached. Top 50 entries share $250.

## The post

Posted from [@Yetu891](https://x.com/Yetu891), quoting make.fun's post, with the photo
`post-photo.png` (made by the agent for this post) attached. The post's text carries the
required line `Make your own bounty on @makefunai: https://make.fun/sponsor/new` and my
make.fun play code `makefun-oatmeal-twig-rowboat`.

The post's URL is in [POST.json](POST.json).

## How to run

Requires Node 22+ (stdlib only, no dependencies):

```sh
node main.ts
```

This copies `POST.json` to `/output/POST.json`. For local testing, override
the output directory:

```sh
OUTPUT_DIR=/tmp/post-x-promo-out node main.ts
```
